# Interactive Brokers Python

## Getting started

- Install [Python](https://www.python.org/downloads/windows/)
- Install the [IB Gateway](https://www.interactivebrokers.co.uk/en/trading/ibgateway-stable.php)
- Enable the API port in IB Gateway [link](https://interactivebrokers.github.io/tws-api/initial_setup.html)
- Install [Pandas](https://pandas.pydata.org/docs/getting_started/install.html)

## Libraries used

- [IB-insync](https://github.com/erdewit/ib_insync)
